## Штатный EXE и одноразовая виртуальная машина

На локальной Windows 11 Home Windows Sandbox недоступна. Установленная Windows-VM для испытания штатного очистителя на этой машине не обнаружена. Штатная проверка подготовлена для GitHub-hosted `windows-2022` и `windows-2025` x64. Для запуска `tests/cleanup-hosted.ps1` обязательны признаки GitHub-hosted runner и Windows Server 2022 или 2025. Сценарий управляет штатным окном, проверяет подтверждение удаления, реальные записи реестра, ярлыки, задачи, службы, коды Win32, завершение приложения и остатки на диске. Отчёт JSON содержит хэши обоих релизных EXE и флаг готовности каталогов для проверки новой установки.

~~~powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\tests\cleanup-hosted.ps1 -CleanupExe .\release\Pulse-Cleanup.exe -PulseExe .\release\Pulse.exe -Report .\test-runs\cleanup-hosted.json
~~~
